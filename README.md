
# UDP Team Chat App

WinForms-приложение для командного чата по UDP с отдельным сервером, авторизацией, групповыми чатами, приватными сообщениями и списком контактов.


imgur: https://imgur.com/a/U946Ong


## Функционал

- Регистрация и вход пользователя.
- Подключение клиента к UDP-серверу.
- Отправка и получение сообщений в групповых чатах.
- Создание нового группового чата с выбранными контактами.
- Приватная переписка с контактами.
- Добавление, удаление, блокировка и разблокировка контактов.
- Загрузка списка чатов и контактов после входа.
- Хранение данных через общий проект `ChatLibrary` и настроенный `ChatContext`.

## Структура проекта

- `UdpTeamChatApp` - WinForms-клиент.
- `UdpTeamChatAppServer` - UDP-сервер, который принимает пакеты и обрабатывает команды.
- `ChatLibrary` - общие модели, пакеты, сервисы и доступ к базе данных.
- `UdpTeamChatGeneralApp.sln` - solution со всеми тремя проектами.

## Как запустить

1. Установите .NET 8 SDK и Visual Studio 2022 с workload `.NET desktop development`.
2. Откройте `UdpTeamChatGeneralApp.sln` в Visual Studio или терминале.
3. Запустите сервер:

```powershell
dotnet run --project .\UdpTeamChatAppServer\UdpTeamChatAppServer.csproj
```

4. Запустите клиент:

```powershell
dotnet run --project .\UdpTeamChatApp\UdpTeamChatApp.csproj
```

5. В клиенте зарегистрируйтесь или войдите.
6. Проверьте настройки подключения:
   - `Server IP`: `127.0.0.1`
   - `Server Port`: `10000`
   - `Local Port`: например `10020`
7. Нажмите `Connect`, после этого можно отправлять групповые и приватные сообщения.

Для запуска нескольких клиентов откройте несколько экземпляров `UdpTeamChatApp` и задайте каждому клиенту свой `Local Port`, например `10020`, `10021`, `10022`.

## Что было улучшено в интерфейсе

- Пересобран главный экран клиента на более удобную структуру: отдельная верхняя панель подключения, зона группового чата и зона приватных сообщений.
- Добавлены аккуратные отступы, единая цветовая схема, улучшенные шрифты и визуально выделенные основные кнопки.
- Поля подключения перенесены в одно понятное место: IP сервера, порт сервера и локальный порт клиента теперь находятся рядом.
- Экран входа и экран регистрации оформлены как отдельные чистые формы по центру окна.
- Пароль в полях входа и регистрации теперь скрывается системной маской.
- Диалог создания чата получил более удобный layout, список контактов и понятную кнопку создания.
- Исправлена экранная навигация кнопки возврата из регистрации на вход.
- Исправлен поиск `ChatLibrary\Data\appSettings.json`: приложение теперь находит файл настроек из папки проекта независимо от текущей рабочей директории запуска.

## Важные порты

- UDP-сервер слушает порт `10000`.
- Клиентский локальный порт задается в поле `Local Port`.
- При запуске нескольких клиентов на одном компьютере локальные порты должны быть разными.

## Примечание

Функциональная логика обмена UDP-пакетами, работа с сервисами, моделями, контактами, чатами и серверными обработчиками не изменялась. Правки сделаны вокруг интерфейса клиента и диалога создания чата.
